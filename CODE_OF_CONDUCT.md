# Code of conduct

SystemOne Builder adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every project space: issues, pull requests, discussions and the
systemone.dev community.

In short: be respectful and constructive, assume good faith, and keep criticism about the
work, not the person. Harassment, personal attacks and discriminatory language are not
tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainers at **conduct@systemone.dev**.
Reports are handled confidentially. Maintainers who do not follow the code of conduct
may face the same consequences as anyone else.
